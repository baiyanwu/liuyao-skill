# 六爻纳甲占卜 Skill

传统六爻（纳甲筮法）完整流程的 AI Agent Skill，基于京房八宫体系。

## 功能

完整的传统六爻占卜流程：

1. **起卦** — 三枚铜钱法（手动掷钱 / 给定数值 / 随机生成）
2. **纳甲** — 内外卦分别配天干地支，严格遵循京房口诀
3. **装六亲** — 以宫五行为基准的五行生克关系
4. **安六神** — 按日干起例（青龙朱雀勾陈螣蛇白虎玄武）
5. **定世应** — 八宫体系（本宫→一世→二世→三世→四世→五世→游魂→归魂）
6. **查空亡** — 旬空自动推算
7. **查月破** — 月建冲爻判断
8. **变卦** — 动爻变出之卦的完整装卦

## 数据来源

- 排盘数据基于京房八宫六十四卦体系（惠栋《易汉学》八宫卦次图）
- 纳甲规则遵循传统京房易传
- 参考资料：yifanzi.com 京房八宫与六十四卦装卦表

## 使用方法

### 命令行

```bash
# 简略排盘（默认）
python3 scripts/liuyao.py -q "测财运"

# 完整八步推导
python3 scripts/liuyao.py -q "测事业" --full

# 手动输入六爻值（初爻在前, 6/7/8/9）
python3 scripts/liuyao.py -q "测感情" -c 7 8 9 6 7 8

# 指定日期
python3 scripts/liuyao.py -q "测投资" --date 2026-04-18

# JSON输出
python3 scripts/liuyao.py -q "测健康" --json

# 可复现（指定种子）
python3 scripts/liuyao.py --seed 42 -q "测试"
```

### 爻值说明

| 值 | 名称 | 含义 |
|---|------|------|
| 7 | 少阳 | 静阳爻 |
| 8 | 少阴 | 静阴爻 |
| 9 | 老阳 | 阳动爻（阳→阴变）|
| 6 | 老阴 | 阴动爻（阴→阳变）|

### 作为 Hermes Agent Skill

将整个目录复制到 `~/.hermes/skills/六爻占卜/` 即可自动注册。

```
~/.hermes/skills/六爻占卜/
├── SKILL.md           # 技能定义文件
└── scripts/
    └── liuyao.py      # 核心引擎
```

## 纳甲口诀

```
乾金甲子外壬午，坎水戊寅外戊申，
艮土丙辰外丙戌，震木庚子外庚午，
巽木辛丑外辛未，离火己卯外己酉，
坤土乙未外癸丑，兑金丁巳外丁亥。
```

**注意**：内卦和外卦的地支起点不同，这是实现中最容易犯的错误。

| 八卦 | 内卦地支(初→三) | 外卦地支(四→上) |
|------|----------------|----------------|
| 乾 | 子、寅、辰 | 午、申、戌 |
| 坤 | 未、巳、卯 | 丑、亥、酉 |
| 震 | 子、寅、辰 | 午、申、戌 |
| 巽 | 丑、亥、酉 | 未、巳、卯 |
| 坎 | 寅、辰、午 | 申、戌、子 |
| 离 | 卯、丑、亥 | 酉、未、巳 |
| 艮 | 辰、午、申 | 戌、子、寅 |
| 兑 | 巳、卯、丑 | 亥、酉、未 |

## 输出模式

### 简略模式（默认）
排盘汇总表 + 世应 + 空亡月破 + 动爻。适合快速起卦后进入断卦环节。

### 完整模式（--full）
展示完整的八步推导过程：起卦→定卦→纳甲→六亲→六神→世应→空亡月破→变卦。适合学习和验证。

## 断卦流程（Agent 使用）

1. **起卦方式选择** — 让用户选择手动掷钱 / 给数值 / 随机生成
2. **简略排盘** — 展示排盘结果
3. **追问占事** — 详细了解具体事项后才能断卦
4. **动态断卦** — 根据实际占事取用神，逐层分析
